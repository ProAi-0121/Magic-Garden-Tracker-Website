How it works

  • Size → scale: scale = weight ÷ base weight (each crop has a base kg).
  • Multiplier: elemental mutations add (each adds mult−1); Gold/Rainbow replace (×25 / ×50).
  • Formula: round(baseSellPrice × scale × mutMult), then friend bonus.
  • Range: the game rounds the real weight to the displayed size, so real value can be a bit above or below — that's the ±range shown.
